# Banking-Customer-Demographics-PowerBI
# 📊 Banking Customer Demographics & Portfolio Analysis | Power BI Dashboard

An interactive and professional end-to-end Business Intelligence dashboard built using **Power BI Desktop**, designed to analyze banking customer portfolios, demographic distributions, and customer acquisition trends.

---

## 🚀 Project Overview
This project simulates real-world banking analytics, transforming raw client datasets into actionable visual insights. It helps stakeholders understand customer segmentation based on age, gender, nationality, and growth trends over time.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For data visualization, modeling, and dashboard creation.
* **Power Query Editor:** For data cleaning, transformation, and creating conditional columns (Age Groups).
* **DAX (Data Analysis Expressions):** For writing custom measures like `Total Clients` and `Average Age`.
* **Excel / CSV:** As the primary data source.

---

## 📈 Key Features & Dashboard Components
1. **KPI Summary Cards:**
   * **Total Clients:** High-level count of the bank's active customer base.
   * **Average Age:** Average age metric representing the core demographic.
2. **Demographic & Portfolio Breakdown:**
   * **Donut/Bar Charts:** Visualizing client distribution across different Nationalities and Genders (Sex).
3. **Acquisition Trends:**
   * **Line Chart:** Tracking the growth trend of clients joining the bank over time (`Joined Bank`).
4. **Interactive Slicers / Filters:**
   * Dynamic filtering capabilities by `Age Group` (Young Adults, Adults, Senior Citizens) and `Nationality` to slice and dice data seamlessly.
